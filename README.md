# Cascade

AI study assistant that routes each question to the cheapest model likely to answer it correctly, verifies the answer, and escalates to a stronger model only when the check fails.

Frontier-quality tutoring at a fraction of frontier cost — so it works where money is the barrier.

**Status:** early build (Phase 0 — foundation). See [`CLAUDE.md`](CLAUDE.md) for the full spec, architecture, and build order.
